# Voice source, prosodic style, and learner responses

R analysis and figure-generation code accompanying the manuscript:

> Wang, Y., Zhu, J., McGrane, J., Hopfenbeck, T. N., Lu, H., Shi, Y., Ji, Y., Ke, C., Chen, Z., & Niu, Q.  
> **Effects of voice source and prosodic style on learner ratings, learning outcomes, and arousal.**  
> *npj Science of Learning* (under review).

The study compared five instructional narration conditions (human neutral, human calm, AI neutral, AI calm, and AI energetic) across two science lessons with 233 eighth-grade students. An independent perceptual validation study involved 90 university listeners.

## Repository contents

|File|Purpose|
|-|-|
|`analysis_main.R`|Statistical analyses and supplementary results|
|`figures_main.R`|Main-text Figures 2–5|
|`figS1_acoustic.R`|Supplementary Figure S1, using published acoustic summaries|
|`data/README.md`|Data availability note|
|`.gitignore`|Excludes research data and local output files|

Figure 1 is a schematic, not generated by these scripts.

## Data availability

The de-identified learner data, the perceptual validation data, and the acoustic feature files are available upon request from the first author and corresponding author, subject to the conditions of the approved research ethics protocol and applicable data protection requirements.

Descriptive statistics, model results, perceptual validation summaries, and acoustic characteristics of the narration recordings are provided in the manuscript's Supplementary Information.

The underlying datasets are not hosted in this public repository. The repository contains analysis and figure-generation code, but the full statistical analyses cannot be rerun using the public repository alone.

## Running the code

To generate Supplementary Figure S1 from the acoustic values reported in Supplementary Table S2, run from the repository root:

```r
install.packages(c("dplyr", "tidyr", "ggplot2"))
source("figS1_acoustic.R")
```

Once the required packages and approved data files are available, run:

```r
source("analysis_main.R")
source("figures_main.R")
```

By default, the scripts read authorized data from `data/` and write results to `outputs/` or `figures/`. These locations can be changed with the `NPJ_DATA_DIR`, `NPJ_OUT_DIR`, and `NPJ_FIG_DIR` environment variables. Generated results and local data are excluded from version control.
