# Data availability

The de-identified learner data from the classroom experiment, the perceptual validation data, and the acoustic feature files are available upon request from the first author and corresponding author, subject to the conditions of the approved research ethics protocol and applicable data protection requirements.

These datasets are not included in this public repository. Descriptive statistics, model results, perceptual validation summaries, and acoustic characteristics of the narration recordings are provided in the manuscript's Supplementary Information. The full analyses cannot be reproduced from this public repository without access to the underlying data.
